한눈에 보는 순서

단계해야 할 일핵심 확인
1추천 링크로 접속공식 도메인과 추천코드 HNEBXFA7 확인
2이메일 또는 휴대전화 인증가장 최근에 받은 인증번호 입력
3비밀번호 설정다른 사이트와 겹치지 않는 강한 비밀번호
4KYC 본인인증신분증 정보와 얼굴 인증 완료
5OTP·패스키 설정복구키를 온라인이 아닌 곳에 보관

1. 계정 생성

  1. 추천 링크 접속

    위 버튼으로 가입 화면에 접속합니다. 링크가 앱으로 전환되더라도 가입 확정 전 추천코드 입력란에 HNEBXFA7이 표시되는지 다시 확인합니다.

  2. 이메일 또는 휴대전화 인증

    자주 사용하는 본인 이메일 또는 휴대전화 번호를 입력합니다. 인증번호가 오지 않으면 스팸함, 문자 차단, 국가번호와 입력 오타를 확인합니다.

  3. 로그인 비밀번호 설정

    대문자·소문자·숫자·특수문자를 조합하고 이메일 비밀번호와 다르게 설정합니다. 비밀번호를 메신저나 사진첩에 저장하지 않습니다.

가입 전에 확인하세요. 추천코드는 가입 완료 후에는 변경이 제한될 수 있습니다. 계정을 만들기 전에 코드가 화면에 표시되는지 반드시 확인하세요.

2. KYC 본인인증

  • 거주 국가와 실제 신분증 발급 국가를 정확하게 선택합니다.
  • 신분증 전체 모서리가 보이고 반사광·흔들림이 없도록 촬영합니다.
  • 얼굴 인증은 밝은 곳에서 안경·모자·마스크를 벗고 진행합니다.
  • 국내 거래소와 자산을 주고받을 계획이라면 이름과 생년월일이 일치하는지 확인합니다.

3. 가입 직후 보안 설정

  • 인증 앱 OTP 또는 패스키를 추가합니다.
  • OTP 설정키·복구키는 종이에 기록하거나 오프라인으로 보관합니다.
  • 로그인 기기와 최근 활동에서 모르는 기기가 없는지 확인합니다.
  • 출금 전에는 피싱 방지 코드와 출금주소 관리 기능을 검토합니다.
OTP·비밀번호·복구키는 누구에게도 알려주지 마세요. 공식 고객센터를 사칭해 OTP를 요구하는 경우가 있습니다. 실제 고객센터는 절대 요구하지 않습니다.
