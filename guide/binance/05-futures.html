선물거래는 원금을 모두 잃을 수 있습니다. 레버리지를 쓰면 손실이 빠르게 확대되고, 가격이 청산가격에 닿으면 포지션이 강제로 종료됩니다. 감당 가능한 금액만 사용하세요.

1. 선물 계정과 자금 준비

  • Futures 메뉴에서 USDⓈ-M 선물 계정을 활성화합니다.
  • 현물 또는 Funding 계정의 USDT를 USDⓈ-M Futures 계정으로 내부 이체합니다.
  • 선물 계정에는 감당 가능한 금액만 분리해 두는 것이 좋습니다.

2. 거래 설정 이해하기

설정의미주의점
Long / Short상승 / 하락 방향 포지션반대 방향 선택 시 손실 발생
Cross선물 계정 잔액을 공통 증거금으로 사용다른 포지션과 잔액에도 영향 가능
Isolated포지션별 증거금 분리배정 증거금이 부족하면 해당 포지션 청산 가능
Leverage증거금 대비 더 큰 포지션 운용높을수록 청산가격이 가까워질 수 있음
One-way / Hedge순포지션 1개 / 롱·숏 동시 보유반대 주문이 기존 포지션을 줄일 수 있음

3. 주문하기

  1. 거래 페어 선택

    BTCUSDT Perpetual처럼 거래할 무기한 선물 상품을 선택합니다.

  2. 시장가 또는 지정가 선택

    시장가는 빠른 체결, 지정가는 원하는 가격 통제가 목적입니다. 시장가에는 슬리피지, 지정가에는 미체결 위험이 있습니다.

  3. 수량 입력

    증거금이 아니라 레버리지가 반영된 포지션 명목가치가 얼마인지 확인합니다.

  4. 롱 또는 숏 선택

    상승 예상은 Buy/Long, 하락 예상은 Sell/Short입니다. 포지션 모드를 함께 확인합니다.

4. 포지션 관리

  • Entry Price, Mark Price, Liquidation Price, Margin Ratio와 미실현 손익을 확인합니다.
  • TP/SL로 손절·익절 조건을 설정하고 실제 등록됐는지 Open Orders에서 확인합니다.
  • 무기한 선물은 현재 펀딩비율과 다음 정산시간을 확인합니다.
  • 포지션 종료 후 남은 지정가·TP/SL 주문이 없는지 확인합니다.
