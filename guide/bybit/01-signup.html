1. 계정 생성

  1. 가입 페이지 접속

    위 버튼의 지정 링크로 바이비트 가입 페이지에 접속합니다.

  2. 거주 국가 선택

    거주 국가를 선택합니다. 지역 규정에 따라 이용 가능한 서비스가 달라질 수 있습니다. 실제 거주지와 다르게 선택하지 마세요. 나중에 KYC 정보와 어긋나면 문제가 됩니다.

  3. 이메일 또는 휴대전화 입력

    이메일 가입이 계정 관리와 보안 설정 측면에서 편리합니다.

  4. 가입코드 확인

    가입 화면의 Referral / Affiliate Code 항목에 19796이 적용되어 있는지 확인합니다. 비어 있다면 직접 입력합니다.

  5. 인증 및 비밀번호 설정

    이메일 또는 SMS 인증을 완료하고 계정 비밀번호를 설정합니다. 다른 사이트와 겹치지 않는 비밀번호를 사용합니다.

  6. 신원인증 및 보안 설정

    계정 생성 후 Identity Verification(KYC)을 진행하고 Google Authenticator(2FA)를 등록합니다.

2. 가입코드에 대해

  • 코드는 가입 단계에서 적용 여부를 먼저 확인하는 것이 가장 안전합니다.
  • 2026년 기준 일부 미등록 계정은 가입 후 14일 이내에 제휴 코드를 추가할 수 있지만 조건이 있으므로, 처음부터 정확히 입력하는 것을 권장합니다.
  • 프로모션·리워드 조건은 시점과 계정별로 달라질 수 있으므로 가입 화면의 실제 조건을 확인하세요.
확인되지 않은 혜택을 전제로 가입하지 마세요. 리워드·수수료 할인 조건은 지역과 시점에 따라 달라집니다. 이 페이지는 가입 절차 안내이며 특정 혜택을 보장하지 않습니다.

3. 가입 직후 보안 설정

  • Google Authenticator(2FA)를 등록합니다. 온체인 출금에 필요합니다.
  • 2FA 설정키·복구키는 종이에 기록하거나 오프라인으로 보관합니다.
  • 이메일 인증도 함께 설정합니다. 출금 시 요구될 수 있습니다.
  • 로그인 기기와 최근 활동에서 모르는 기기가 없는지 확인합니다.
2FA 코드·비밀번호·복구키는 누구에게도 알려주지 마세요. 공식 고객센터를 사칭해 코드를 요구하는 경우가 있습니다. 실제 고객센터는 절대 요구하지 않습니다.
