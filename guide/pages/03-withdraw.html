출금의 핵심 원칙

받는 거래소에서 입금주소·네트워크·MEMO를 먼저 확인한 뒤 바이낸스 출금을 진행합니다. 블록체인 출금은 완료 후 취소하기 어렵습니다. 주소와 네트워크가 가장 중요합니다.

1. 받는 거래소에서 준비

  • 입금할 코인과 지원 네트워크를 확인합니다.
  • 현재 입금주소를 복사하고, 필요한 경우 MEMO·태그도 함께 복사합니다.
  • 입금 일시 중단, 최소 입금 수량과 계정주 확인 안내를 확인합니다.

2. 바이낸스에서 출금 신청

  1. 출금 메뉴 이동

    앱에서 Assets → Send로 이동한 뒤 출금할 코인을 선택하고 On-Chain Withdraw를 선택합니다.

  2. 주소와 네트워크 입력

    받는 거래소에서 복사한 주소를 붙여넣고, 동일한 네트워크를 선택합니다. 자동 선택되더라도 직접 비교합니다.

  3. 수량·수수료 확인

    출금 수수료가 차감된 실제 수취 예정 수량이 받는 거래소의 최소 입금액 이상인지 확인합니다.

  4. 수취 정보 입력

    화면에서 수취 플랫폼·주소 소유자·출금 목적 등을 요구하면 사실대로 입력합니다. 국내 거래소 입금은 계정주 확인이 추가될 수 있습니다.

  5. OTP·패스키 인증

    보안 인증을 완료한 뒤 출금 상태를 확인합니다. 인증번호는 타인에게 제공하지 않습니다.

3. 출금 후 확인

  • Processing — 바이낸스 출금 처리 중입니다.
  • Completed — 블록체인으로 전송됐으며 TxID를 확인할 수 있습니다.
  • 바이낸스 완료 후에도 받는 거래소가 요구하는 블록체인 확인과 계정주 확인 때문에 반영까지 시간이 걸릴 수 있습니다.
모르는 사람의 요청으로 출금하지 마세요. 사기 가능성이 있으므로 출금을 중단하고 수취인을 다시 확인하세요.
