바이낸스 입금 방법

입금주소·네트워크·MEMO 확인과 소액 테스트 순서

입금의 핵심 원칙

받는 곳인 바이낸스에서 먼저 입금주소와 네트워크를 확인한 뒤, 보내는 거래소에서도 같은 코인·같은 네트워크를 선택합니다. 처음 사용하는 주소는 소액 테스트가 우선입니다.

2입금 네트워크 선택보내는 거래소가 지원하는 동일 네트워크

5소액 테스트 후 본 전송TxID와 입금 상태 확인

1. 바이낸스 입금주소 발급

  1. 입금 메뉴 이동

    앱에서 Add Funds 또는 Deposit → On-Chain Deposit으로 이동하고 입금할 가상자산을 선택합니다.

  2. 네트워크 선택

    ERC20, TRC20, BEP20처럼 같은 코인에도 여러 네트워크가 있을 수 있습니다. 보내는 거래소가 지원하는 네트워크와 반드시 동일해야 합니다.

  3. 주소·MEMO 복사

    주소를 직접 입력하지 말고 복사합니다. XRP·XLM 등 일부 자산은 MEMO 또는 태그가 필요하므로 둘 다 입력해야 합니다.

네트워크를 틀리면 자산을 잃을 수 있습니다. 수수료가 싸다는 이유로 임의의 네트워크를 고르면 안 됩니다. 호환성이 수수료보다 우선입니다.

2. 보내는 거래소에서 출금

  • 출금할 코인과 바이낸스 입금 코인이 같은지 확인합니다.
  • 출금 네트워크와 바이낸스 입금 네트워크를 문자 단위로 비교합니다.
  • 주소의 앞 4~6자리와 마지막 4~6자리를 비교합니다.
  • 실제 도착 수량이 바이낸스 최소 입금 수량 이상인지 확인합니다.
  • 국내 거래소를 이용한다면 계정주 확인·트래블룰 안내에 따라 수취 거래소와 본인 정보를 정확하게 입력합니다.

3. 입금 상태 확인

  1. 보내는 거래소의 출금 상태 확인

    출금 신청만 접수되고 블록체인으로 전송되지 않았다면 TxID가 아직 생성되지 않을 수 있습니다.

  2. TxID와 네트워크 확인

    TxID가 생성되면 블록체인 확인이 진행됩니다. 네트워크별 필요한 확인 횟수를 충족한 뒤 바이낸스 잔액에 반영됩니다.

  3. 미반영 시 점검

    네트워크, 주소, MEMO, 최소 입금 수량과 바이낸스 지갑 점검 여부를 확인합니다. 같은 작업을 반복하기보다 기존 전송 상태를 먼저 확인합니다.

자주 발생하는 실수

실수결과·해결
수수료가 싼 네트워크를 임의 선택받는 거래소가 지원하지 않으면 자산 손실 가능
MEMO·태그 누락자동 반영되지 않을 수 있어 복구 절차가 필요
