비트겟 가입 방법

추천코드 fc0d 확인부터 신원인증과 2FA 설정까지

처음이라면 이 순서입니다

비트코인을 처음 시작하는 경우 보통 거래소 가입 → 본인인증(KYC) → 입금 → 구매 순서로 진행합니다. 이 글은 그중 첫 단계인 비트겟 가입 방법을 초보자 기준으로 정리한 안내입니다. 가입 자체는 5분 내외로 끝나고, 신원인증에 시간이 조금 더 걸립니다.

1. 계정 생성

  1. 가입 링크 접속

    위 버튼으로 가입 화면에 접속합니다. 링크가 앱으로 전환되더라도 가입을 확정하기 전에 추천코드 입력란에 fc0d가 표시되는지 다시 확인합니다. 비어 있다면 직접 입력하면 됩니다.

  2. 이메일 또는 휴대폰 번호 입력

    자주 사용하는 본인 이메일 또는 휴대폰 번호를 입력합니다. 인증번호가 오지 않으면 스팸함, 문자 차단, 국가번호와 입력 오타를 확인합니다.

  3. 비밀번호 설정

    비트겟 공식 안내 기준으로 8~32자이며 숫자, 영문 대문자, 특수문자를 각각 하나 이상 포함해야 합니다. 이메일 비밀번호와 다르게 설정하고 메신저나 사진첩에 저장하지 않습니다.

  4. 인증번호 입력

    이메일 또는 휴대폰으로 받은 6자리 인증번호를 입력하면 가입이 완료됩니다. 인증번호는 유효시간이 짧으므로 가장 최근에 받은 번호를 사용합니다.

가입 전에 확인하세요. 추천코드는 가입 완료 후에는 변경이 제한될 수 있습니다. 계정을 만들기 전에 코드가 화면에 표시되는지 반드시 확인하세요.

2. 신원인증(KYC)

로그인 후 프로필 → Identity Verification(신원인증) 메뉴에서 진행합니다. 거주 국가, 신분증 종류, 이름을 입력하고 신분증 촬영과 얼굴 인증을 거칩니다.

  • 입력하는 정보는 실제 신분증과 정확히 일치해야 합니다. 한 글자라도 다르면 반려됩니다.
  • 신분증 전체 모서리가 보이고 반사광·흔들림이 없도록 촬영합니다.
  • 얼굴 인증은 밝은 곳에서 안경·모자·마스크를 벗고 진행합니다.
  • 국내 거래소와 자산을 주고받을 계획이라면 영문 이름과 생년월일이 일치하는지 확인합니다.

3. 가입 직후 보안 설정

  • Google Authenticator(2FA)를 활성화합니다. 출금할 때 필요합니다.
  • 2FA 설정키·복구키는 종이에 기록하거나 오프라인으로 보관합니다.
  • 이메일·휴대폰 보안 설정도 함께 점검합니다.
  • 로그인 기기와 최근 활동에서 모르는 기기가 없는지 확인합니다.
인증번호·2FA 코드·비밀번호는 누구에게도 알려주지 마세요. 공식 고객센터를 사칭해 코드를 요구하는 경우가 있습니다. 실제 고객센터는 절대 요구하지 않습니다. 가입 주소가 피싱 사이트가 아닌 공식 도메인인지도 확인하세요.
